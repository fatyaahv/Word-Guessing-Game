Word Guessing Game

A cute and colorful twist on the classic word guessing game! ✨
Built with Python and Tkinter, this project lets you guess secret words in a pink-themed GUI with a sprinkle of positivity and fun. 💅

💖 Features

🌸 Beautiful pink-themed GUI made with Tkinter

💬 Interactive word guessing with instant feedback

🧁 Randomly chosen words from a girly-themed word bank

🌷 Encouraging messages and simple gameplay

💻 Perfect for beginners learning Python and GUI programming

🪄 How to Play

Run the Python file:

python word_guessing_game.py


A lovely pink window will appear.

Guess letters one by one! 💌

Each correct guess reveals part of the word.

Try to guess the full word before you run out of attempts! 💕

🧚‍♀️ Technologies Used

🐍 Python 3

🪞 Tkinter (for GUI)

💫 Random module
